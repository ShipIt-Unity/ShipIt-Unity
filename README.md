# ShipIt

**Focused tools for Unity teams.**

ShipIt builds practical tools for Unity developers, including backend integrations for services your team operates and tools for project review.

[Visit shipitunity.com](https://shipitunity.com)

## Product guides

These public GitHub repositories contain product information only. They do not include toolkit source code or package files. For current product details and availability, start with the [ShipIt website](https://shipitunity.com).

- [ShipIt Supabase Toolkit](https://github.com/ShipIt-Unity/shipit-supabase-toolkit) — connect Unity projects with a Supabase backend your team operates.
- [ShipIt AWS Toolkit](https://github.com/ShipIt-Unity/shipit-aws-toolkit) — connect Unity projects with AWS services your team operates.
- [ShipIt Firebase Toolkit](https://github.com/ShipIt-Unity/shipit-firebase-toolkit) — connect Unity projects with Firebase services your team operates.
- [ShipIt License Auditor](https://github.com/ShipIt-Unity/shipit-license-auditor) — review third-party license and attribution information in a Unity project.
